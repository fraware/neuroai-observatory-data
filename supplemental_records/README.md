# Supplemental source records

Supplemental source registers in this directory preserve the source identity and evidence metadata recorded for the corresponding observatory lineage.

A later operational route failure or source lifecycle transition does **not** rewrite a historical supplemental source record. Current retrieval-route policy and evidence-bound lifecycle resolution are maintained separately under the development curation/operational layer.

For example, a source that is verified `NO_LONGER_LISTED` retains its historical source record; the lifecycle state means only that the declared current official publisher surfaces no longer list that exact source identity under the registered checks. It does not establish why the source disappeared or imply any assessment, scientific, clinical, regulatory, commercial, governance, canonical-release, or publication conclusion.
